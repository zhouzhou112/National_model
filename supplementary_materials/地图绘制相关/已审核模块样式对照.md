## 沿用与必要适配

| 构件 | 当前实现 |
|---|---|
| 底图和投影 | 相同省界、九段线、原始中国底图 `.prj`，全部重投影；主图范围和纵横比与模块01/03一致 |
| 比例尺 | 完全沿用模块01布局：左下，水平500000投影米，端点“0”“500 km”，字号5pt，线宽0.55pt |
| 指北针 | 右上预留区直立，箭长为y跨度9%，`N`为6.2pt；投影北约定与模块01一致 |
| 南海插图 | 右下 `[0.785,0.055,0.180,0.340]`；线文件完整边界外扩10%；白底、淡灰边界、虚线线型、0.45pt边框；不叠加定量值 |
| 色阶 | 模块01三套浅色—蓝／红／青；零值可见。正负量使用蓝—浅色—红，新增语义在图注说明 |
| 色条 | 水平、单位清楚、3–5个整洁主刻度；归一化范围仍覆盖全部数据，不因刻度取整截掉极值；全零字段只标0 |
| 字体与导出 | Arial及嵌入字体、精确宽7英寸、450dpi PNG和PDF；不使用tight裁剪 |
| 数据层顺序 | 数据绘制后统一加边界、比例尺、指北针、插图，再固定等比例范围；不让后续散点／格网重设布局 |
| 多主题适配 | 风光四技术各自独立色标；储能同单位用共同范围；不同量纲不共享色标。图题与面板标题可保留，解释写在独立中文图注中 |

本次撤回了未经作者要求新增的局部真北倾斜箭头和测地线倾斜比例尺。水平标尺是投影距离约定，不等于全国任何位置的精确测地距离；该说明留在文档，不向图面增加小字。

## 防止复发的检查

`export`检查每个面板的比例尺显示坐标y差为0、指北针显示坐标x差为0，且位于画框内；同时检查投影x/y比例相等、文字不越界、字体嵌入、PDF和PNG尺寸。PDF渲染流程逐图核对实际页面中的`N`和`500 km`数量等于地图面板数量，再逐页目视核对南海插图和图例布局。
