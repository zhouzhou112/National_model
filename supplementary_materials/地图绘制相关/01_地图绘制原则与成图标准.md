# 地图绘制原则与成图标准

## 1. 规范优先级

先遵循当前任务的作者要求，再遵循较晚的作者决定，随后使用已有地图模板与函数。当前提取到的较晚决定见 `midterm_base_v3/README_ZH.md`（2026-10-21）：参考 `journal_codex_v2`，英文图内标签、蓝红青色系、尽量使用线性坐标／色标，图内不放方法和限制等说明性小字；解释放在中文说明或图注中。不再默认调用 Nature 系列绘图技能。

`journal_codex_v2` 是视觉参照，不是所有实现细节的强制标准。其代码含平方根色标、对称对数轴和图内脚注；较晚的 `midterm_base_v3/scripts/build.py` 使用 `Normalize` 和无说明脚注样式，应优先参考。其作者审美验收仍未确认。

## 2. 科学表达与数据原则

- 从原始或已核验的最终矢量、栅格、表格绘图；不描摹截图，不用生成式图像伪造地图或科学数据。
- 先明确图要说明的结论、变量、年份、情景、单位及聚合尺度，再决定分面、色标和图例。容量（MW/GW）、能量（MWh/GWh）、容量因子（fraction）、单位容量价值不能混用。
- 表连接按稳定主键进行，先核对唯一性、未匹配项和重复项。格网用 `grid_uid`；省份用模型 `province_code` 与省界 `gb` 的显式映射，不能依赖名称乱码或行顺序。
- 底图覆盖34个省级要素，模型优化覆盖31省；无模型数据区域保留地理背景，不能自动填成零。有效零值、缺测、范围外、未选中候选点分别处理。
- 0.25°格网不是等面积固定千米方格。若由经纬度中心重建格网，在确认原格心定义后，用 `lon±0.125°`、`lat±0.125°` 构造地理多边形，再重投影。不得在投影米坐标中直接加0.125来造格网。
- 上游适宜性图使用16,739网格范围；模型结果图按对应模型／release 的实际点集，当前本地为16,609点。剔除130点已有审计，不能直接混用掩膜。
- 集中式光伏（utility-scale PV）与分布式光伏（distributed PV）分别显示；陆上风电与海上风电是否合并由图的科学问题决定，并披露。不得取不同技术格内最大值冒充总量。
- 总装机、当期新增、跨年净变化分别使用相应字段；跨年总装机差不能替代当期新增。
- 省际通道连线、城市负荷中心和省内边属于规划模型的空间代理。图注需说明代表点连线不是真实线路走向，也不是交流／直流电气潮流（AC/DC power flow）。水电省级聚合量不得虚构为真实电站坐标。
- 现有装机中的匿名残差分配是统计闭合，不能画成已识别项目或逐站实测。CCS储量（Mt CO2）与年度注入能力（Mt CO2/a）分开。
- 工程影子价格（shadow price）不是市场结算价；发表对偶图时在图注说明 `BARRIER_DUAL_ENGINEERING_GRADE`、`BarConvTol` 及变量定义。不能因为无负价就宣布价格还原正确。

## 3. 固定地图构成

固定地理输入的完整路径见 `02_本机资源与运行环境.md` 和 `resource_inventory.csv`。省界、九段线、点、线、格网和栅格全部转换到目标 `.prj`；保留各数据原有CRS，不能用 `set_crs` 冒充 `to_crs`。

目标CRS实测为 `Asia_North_Albers_Equal_Area_Conic`：WGS84，中央经线105°E，原点纬度30°N，两条标准纬线25°N、47°N，假东／北0，坐标单位米。以 `.prj` 原WKT为准，不凭名称替换成另一个 EPSG。读取省界后令边界为 `(xmin, ymin, xmax, ymax)`、`W=xmax-xmin`，将WGS84点 `(105, 15.5)` 投影后的北坐标记为 `y_cut`：

```python
x0 = xmin - 0.03 * W
x1 = xmax + 0.30 * W
y0 = y_cut
y1 = ymax + 0.06 * W
main_extent = (x0, x1, y0, y1)
box_aspect = (y1 - y0) / (x1 - x0)
ax.set_aspect("equal", adjustable="box")
ax.set_box_aspect(box_aspect)
```

本次计算：`(-2770761.9291, 3657240.7839, -1591610.3369, 3039830.5543)`米，纵横比约 `0.7205101`。优先由源文件重新计算；数字只作核对基准。主图呈紧凑横向，不强行正方形、不拉伸国土，海南以南自然裁切，不把整个南海范围加入主图。顶部空白以旧模板约6%的目标作视觉参考，不把此值当独立地理判据。

**南海插图（inset）**固定右下，轴归一化矩形 `[0.785, 0.055, 0.180, 0.340]`。主图照常绘制源文件，让范围自然裁切；插图显示源文件全部几何和淡色岛屿／海岸背景，不叠加定量格网。现有函数按完整线文件边界外扩10%；若相关岛屿背景仍被裁切，应取相关背景与线文件范围的并集后调整，并记录差异。白底，约0.45 pt灰边框，无坐标刻度、无单独图例。预留右侧空间，不能压住定量数据。

**指北针与比例尺：**既有模板指北针在右上，比例尺在左下，尺度条500 km。令 `xs=x1-x0, ys=y1-y0`：

```text
north_x       = x1 - 0.055*xs
north_tip_y   = y1 - 0.100*ys
north_tail_y  = north_tip_y - 0.090*ys
north_label_y = north_tip_y + 0.015*ys
scale_x       = x0 + 0.120*xs
scale_y       = y0 + 0.100*ys
```

补充技术检查建议（本次新增，不冒充此前作者决定）：现有直立箭头实现沿投影坐标正北，不自动等于箭头位置的真北；500,000米尺度条表示投影距离，不表示全国所有位置均无距离变形。若图的解读依赖方向／测距，应核验局部真北和测地距离并在新版本说明。

## 4. 栅格、显示阈值和色标

- 像元图以最终格网覆盖范围生成显示掩膜：范围外透明／NaN；范围内有效零保留浅色，不能与缺测纯白混淆。DPV更细单元需核对其对应ERA5网格是否属于目标点集。
- 显示掩膜、重采样、色标范围及点大小不改变原始源数据和统计总量。分类数据不使用连续插值；总量型容量栅格的显示重采样不能用于重新推算全国合计。方法和参数写入图注／manifest。
- 默认线性色标；同技术、同指标、不同年份／情景比较使用共同上下限，记录全体比较面板的最小／最大值。不同单位不共用色条；不同技术各自色条时明确说明。
- 蓝红青是固定色系，而非所有旧图都有相同hex。历史适宜性系列为风电 `#0F4D92`、集中式光伏 `#B64342`、DPV `#42949E`；较新结果图主色为蓝 `#16558A`、红 `#B74C45`、青 `#328E91`。**新结果图推荐后者，延续旧系列时沿用该系列现有映射；同一整套图不混用。** 每个顺序色阶由浅色到锚点色，零值可见。
- 正负差值图建议采用以0为中心的发散色标（diverging colour scale）；这是按变量语义作出的新执行建议，不意味着已有所有图均采用该方案。正负区间及是否对称应显式记录。
- 不截掉极值来改善视觉，不擅自采用对数或平方根增强微小值。如确需非线性色标，先说明其必要性并在色条和图注披露。
- `midterm_base_v3` 的 `<1 MW` 格网省略仅是那个历史图的显示约定，**不是通用数据筛选门槛**。新任务默认保留全部有效值；沿用阈值时导出每年每技术省略容量、比例和格网数量，统计仍用全量数据。地图看不到不能解释为严格零。
- 3×2同类地图每指标列共用一条水平色条；3–5个有意义主刻度，避免密集次刻度，标单位。历史整数刻度适用于相应容量／面积量级，不强迫fraction或很小数值取整数。

## 5. 版式与导出

| 项目 | 已确定约定 |
|---|---|
| 绘制后端 | Python / matplotlib；批处理使用`Agg` |
| 字体与背景 | Arial优先，Helvetica／DejaVu Sans后备；白底 |
| 字号 | 地图文字／色条7–8 pt，面板标题8–9 pt；按最终物理尺寸检查 |
| 面板标记 | 左上角粗体小写字母，系列内位置一致 |
| 边线 | 淡灰、细线；按图层约0.35–0.8 pt，不喧宾夺主 |
| 标签 | 论文图默认英文；解释、来源和限制置于图注／独立文档 |
| 宽度 | 单栏85 mm；双栏7.0 in = 177.8 mm |
| 3×2模板 | 7.0×8.60 in = 177.8×218.44 mm（文档常四舍五入为218.4） |
| 输出 | 精确尺寸PDF + 450 dpi PNG；不默认SVG/TIFF |
| PDF文字 | `pdf.fonttype=42`；文字保持字体对象，允许栅格图层嵌入 |
| 尺寸保真 | 不使用`bbox_inches="tight"`；不要在导出后裁切改变物理尺寸 |
| 3×2 PNG | 3150×3870 px；其他布局按宽高×450计算 |

3×2模板共用色条矩形为 `[0.115,0.045,0.270,0.010]` 和 `[0.615,0.045,0.270,0.010]`。其他排版不机械套用8.60英寸高度，先确定尺寸，再保留等比例地图和足够注释空间。

情景标签需按数据域解释：适宜性C/B/O写 `Conservative / Base / Open`；规划模型的Base、Flex-coopt、Base-frozen、Late-entry另成体系，不能把框架B当成适宜性Base或把框架C当成Conservative。

## 6. 每次成图交付检查

1. **数据**：写明具体案例、年份、源文件、字段、单位、主键、筛选、聚合、源SHA；检查连接完整性和图表合计，阈值仅影响显示时同时保存全量表与显示审计。
2. **空间**：检查输入CRS、目标CRS、经纬度顺序、无效几何、点集范围；省界与定量层匹配；主图九段线自然裁切，右下插图保留完整几何且不遮挡数据。
3. **视觉**：逐张以最终尺寸查看PNG及PDF，确认字体、色条、标题、比例尺、指北针、图例无重叠；颜色对比可读，缺测／零值明确，系列色标一致，无地理拉伸。
4. **导出**：核验PDF MediaBox、PNG像素、450 dpi、字体嵌入。脚本运行成功不等于视觉检查通过，更不等于作者审美验收。
5. **归档**：保留`figures/*.pdf/png`、`figure_data/*.csv`、`scripts/`、`qa/`、图注及README。QA记载已通过、未检查和待作者决定事项；不覆盖旧图、正式模块、原始底图和冻结输出。
