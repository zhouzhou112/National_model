# 冷热与 EV 响应合同候选 V1

2026-09-07。父方案为 `optional_service_pools_v1`；本文是明确选择的研究增量，不覆盖原三个
情景或运行中的 Base。候选配置在 `scenarios/response_candidates_v1/`。全部仍未获正式求解资格。

## 1. 文献启发与采用边界

参考 Li et al., *Facilitating megacity electricity decarbonization via grid-interactive demand-side
resource management*, Nature Communications, DOI [10.1038/s41467-026-76799-4](https://www.nature.com/articles/s41467-026-76799-4)。
接收稿 Methods Eq.10–22 区分不参与、智能充电、V2G，并约束设施、停留、到达电量及出发需求；
Eq.46–47 给出补偿意愿分布。本候选吸收“参与群体与可用响应一致、意愿与设施分离”的机制。
这些参数不是全国实测校准；旧 EV 补能义务、归一化可用性和非负冷热库存的代理性质保持明确。

## 2. 冷热同一签约群体的小时响应

输入仍为旧 V5 `U[p,t], D[p,t], a[p,t]`，单位 GW、GW、无量纲。新增常数：

```text
K0[p] = max_full_year_t(max(U[p,t], D[p,t]) / a[p,t])
u[p,t] <= (U[p,t] / K0[p]) * K[p]
d[p,t] <= (D[p,t] / K0[p]) * K[p]
K[p] <= q[p] * K0[p]
```

零包络/零可用率按显式零处理；正包络但可用率为零拒绝。`q` 为外生可签约比例上限，默认为 1。
同一签约群体按年度响应形状同质抽样，是本研究新增假设。它收紧旧 `u<=min(U,aK)`、
`d<=min(D,aK)`，不是数学等价变换。例：全年 K0=1 GW，某小时 U=0.1 GW，签约 K=0.1 GW，
旧约束允许增载 0.1 GW，新约束只允许 0.01 GW，避免部分签约仍取完整群体的该小时潜力。

保留 `u+d<=aK`、BAIT +/-1℃包络、非负连续周期服务库存、0.94/0.92 每小时留存率、
4h/5h 热/冷能量功率比，以及原成本计量口径。未增加欠舒适度，未用日清零替代状态连续性。
短窗口继续保留原窗口 K 上界，再与年度 `q*K0` 取最小值，避免新候选放大旧短窗口可行域；
逐小时比例始终以全年 K0 归一化。没有删除小流量或小负荷，也没有调整任何水库。

## 3. EV 意愿与设施分别生效

保留旧 `alpha`、`beta` 与两池库存，`rho=0.10/0.15`；旧基础参与上限、全国 V2G 容量上限均保留。

```text
alpha <= q_v1g
beta <= rho * q_v2g * alpha
beta <= rho * r_infra
```

`q_v1g` 为原可参与智能充电群体内的签约上限；`q_v2g` 为已签约智能充电群体内 V2G 意愿折减；
`r_infra` 为原 V2G 技术池中具备设施的比例，默认为 1。这是聚合服务池的设施上限，
不是逐停车位并发充电桩模型，也没有新增充电桩投资决策。
设施上限作为 beta 的 UB、意愿作为既有嵌套行系数，未创建额外小时变量或整数变量。

旧 `P_t,D_t,Q_t,W_t,departure_t`、共享充放接口、两池各自周期守恒、充放效率 0.94 均未放宽。
输入中 departure=0、connected_fraction=1 仍是服务代理设定，不能宣称已经实现论文逐车出行约束。
零签约继续严格恢复相同的 Base 电力需求与零服务费用。

## 4. 参与分布、经济参数和候选集合

三份 `case[1,2,3]_*_response_v1.json` 仅采用上述比例合同，q 与设施上限均为 1，真实成本不变。
八份联合情景敏感性均为单独待选方案，不会自动运行：

- `sub1`–`sub4`：按文献 Eq.47 正态分布、标准差/均值=0.5，外生倍率 gamma=0.5/1/1.5/2，
  期望参与率为 15.87%/50%/84.13%/97.72%。只折减既有制冷及 V2G 技术池，不推及供暖/V1G。
  正态分布未截断，因此 gamma=0 时仍有约 2.28% 接受；这是文献数学假设的敏感性，不是行为事实。
- `infra25`、`infra50`：设施上限单独为原 V2G 技术池的 25%、50%，意愿不变。
- `cost_low`、`cost_high`：使用旧 V5 参数注册表已有低/高值，按服务/费用字段的显式倍率加载。
  输入成本文件不变，倍率在情景配置中归档；这些是成组成本边界，不是单因素归因实验。

现有中心成本保持：冷热签约40 CNY/kW-year、每方向激活300 CNY/MWh；V1G签约60、移位300；
V2G增量可用性60、基础设施40 CNY/kW-year、参与150和退化400 CNY/MWh。价格口径为2025不变CNY。

补偿意愿阈值在 `response_evidence.incentive_ledger` 中另存，按 Eq.47 的报价阈值解释；
不将其乘入现有目标、不与真实不便/退化成本重复计费。论文 Eq.9 与 Eq.47 的成本倍率表述存在
量纲歧义，不能声称已复刻作者费用。论文未明确的实际价格年也不能自动当成2025不变价。
这份账本当前记录假设报价，尚不输出基于求解运行量的已实现补贴支出。

## 5. 验收与计算负担

`flexible_response.py` 校验配置、计算比例、解析敏感性费用；未知字段、非有限数、非法比例、
非正成本倍率拒绝。新增冷热比例/参与上限及 EV 意愿/设施检查进入 `optional_portfolio_qc` 硬检查。
旧情景不启用此合同，继续构建原矩阵；不新增供给侧、网络、水库或碳约束。

19项禁止 optimize/presolve/松弛的回归通过；非零EV人工构造向量同时满足两池约束，反例被QC识别。
31省真实2030全年输入的比例系数最小值：供暖2.12e-4，制冷1.38e-6，最大均1。
31省168h（start4368）联合服务块仍为43818变量、62673约束、194676非零元，零整数，
与旧对应服务块同规模；零签约向量原LP QC通过。以上不证明全年优化速度或正式可解性。

原三个情景的2省24h服务矩阵、边界、目标与旧提交完全一致；Base关闭灵活性时仍不建服务变量。
供给侧与Base配置未改。正式8760h入口阻断保留，作者解除禁令并完成资格验收前不得自行求解。

`PYTHONPATH=tests python -m unittest test_flexible_response_no_solve test_portfolio_no_solve -v` 不求解。
