# 求解数据实体迁移、标准核心工作流与 reviews 筛查

## 已完成的实体迁移

作者要求的是把数据从补充材料中剪切出来，而不只是建立路径目录。本轮已执行：

- `supplementary_materials/reviews` 中62个求解、验收、数值实验、分析和备份目录，移入 `CASE_data/02_history` 的四类档案。
- 原 `case_results/by_case`、`deliveries`、`core_library_20261123` 移入 `CASE_data/03_legacy_deliveries`。
- 共65个根目录、17,931个文件、66,624,973,245 bytes（62.0493GiB）。迁移前后逐文件SHA256一致，NTFS文件身份、大小、修改时间均保持。
- 37个论文、SI、参数或输入方法审查目录留在 `reviews`，实体文件共约0.2581GiB。未改 `supplementary_materials/modules` 或在线LaTeX。

37份脚本/配置仍有旧路径引用，因此保留兼容联接，不改写冻结数据、历史manifest或作者论文脚本。目录联接不占第二份大数据。两个旧Base导航目录被其他程序占用，保留空导航骨架并回填两份小README，数据原件仍已全部迁入CASE_data；详细路径见 `locked_navigation_cards.json`。

移动不释放磁盘空间。本轮未删除任何数据文件、未去重、未压缩原件、未运行git gc。旧目录联接可能仍在资源管理器显示，实际数据位置以 `path_migrations.json` 为准，统计不可跟随联接重复计算。

## 新的标准核心

T550已按统一schema生成模块化核心包，本地正式存放在：

`CASE_data/01_cases/<论文正式情景>/<year>/<release>/`

八模块是身份与验收、年度系统与成本、容量/网络/充裕度、运行、柔性、年度约束影子值、碳核算、溯源。26个完整解每案22份核心文件，约20MiB；另外3个失败/排序记录明确不适用。REF柔性条目仍为31省×4服务，状态明确关闭、数值留空。

T550输出 `paper_core_modules_v1_20261124`，压缩包5,073,185bytes，SHA256 `1fead4fc645c7897e9a63ccf0213ff546e66a5fce0ea25e0cf9297b0d046d0a4`。648份包内文件逐项SHA通过。本轮没有新增下载原模型、BarX/BarPi或逐时大数组。新加入的独立碳核算JSON仅从既有年度汇总取原值。

本地入口 `CASE_data/00_案例总览.html`；旧 `case_results/00_案例总览.html` 与逐案书签仍可跳转。每案页面优先显示模块，不再展开大量历史路径。历史文件与T550大文件目录放在溯源入口。

工作流脚本位于 `CASE_data/workflow`，从完整备份/明确验收SHA提取，再模块化打包、限额导入、更新目录。用已完成OPS-Conservative2060进行了独立只读提取，16份科学数据文件与既有提取结果逐字节相同；不调用求解器。

导入器已验证：两个独立批次能增量保留全部案例；重复导入不覆盖数据；篡改包在落盘前被拒绝。当前31个页面、811个链接通过结构检查。浏览器工具禁止访问file URL，因此本轮没有取得新的浏览器截图，不将链接检查冒充视觉验收。

## 哪些过期，哪些应保留

“历史状态已过期”和“数据无价值”分开记录。启动报告中的RUNNING、早期STOP、被否决的数值方案均不能代表当前结果，但它们解释数值规则和门禁如何形成，已归入历史档案，不删除。

| 类别 | 本轮判断 | 后续处理 |
|---|---|---|
| 当前验收、源身份、筛选证书、续接与方法依据 | 仍有价值 | 统一核心＋历史证据保留 |
| 数值稳健性被否决候选、失败启动、排序实验 | 不再作为当前生产结果；仍有诊断价值 | 已归入数值/平台历史，不直接删除 |
| 论文/SI和输入方法审查37目录 | 与求解数据不同 | 留在补充材料，后续另按文稿任务整理 |
| 171份具有对应Python源文件的缓存，约2.07MiB | 可重建缓存候选 | 低优先级，未删除 |
| 9个大副本，约16.803GiB | 本机新SHA与T550 COMPLETE清单一致，远端当前存在且大小一致 | 优先作为下一轮本地副本清理候选；仍须逐项引用与删除授权 |
| 137组同SHA文件（414成员） | 重复字节成立，历史用途未必相同 | 只列候选，不能直接删整组 |

137组重复文件的额外逻辑字节上限为20,878,885,300bytes（约19.445GiB），不是实测可释放空间。与9个远端匹配大副本存在交叉，两个数不能相加。远端证据为既有完整备份清单SHA加本次stat，未声称重新读取散列所有远端大文件。

没有确认任何完整review目录可以整目录删除。最优先可讨论的是REF2030/2040/2050及PLAN2030的原模型和相关BarPi本地副本，而不是删除所有数值实验。逐文件清单见 `large_remote_copy_candidates.csv`，重复组见 `duplicate_groups.csv`，缓存候选见 `regenerable_cache_candidates.csv`。
